# 接客から逃げろ

「服は欲しい。でも店員とは話したくない。」服屋で親切な店員の視界を避け、指定服を全部集めて下のセルフレジでお会計する、スマートフォン向けのステルス鬼ごっこです。各ステージ45秒、全3ステージ。外部ライブラリ・サーバー・データベースは不要です。

## 起動

このフォルダーの **index.html をブラウザーで開く**だけで遊べます。インストールやビルドは不要です。スマートフォンではフォルダー全体を静的Webホスティングに配置してアクセスできます（公開操作は行っていません）。

## 操作

| 操作 | スマートフォン | PC |
| --- | --- | --- |
| 移動 | 左下のスティック | WASD / 矢印キー |
| 服を乱す | 右下のボタン | Space |
| 効果音 | 右上の音ボタン | 同左 |

指定服とアイテムは触れると自動取得します。黄色い扇形が店員の視界です。発見されると「！」と吹き出しが出て追跡されます。棚の向こうへ逃げ、約1.2秒視線を切ると見失い、巡回へ戻ります。追跡中の赤い視界も棚で遮られます。

ぐちゃぐちゃの服は1個まで所持可能。棚の近くで使用すると、その棚に気づいた店員が整理に向かい、約3.5秒服を畳みます。遠い店員や棚の向こうにいる店員は気づきません。使用可能な棚が遠い場合は消費しません。

指定服を全部集めて下のセルフレジの手前に到達すると、自動でお会計が完了してクリアになります。服が不足している間は会計できません。ステージ1・2はクリア画面の「次のステージへ」をタップすると次へ進みます。タップするまではゲームとタイマーが停止します。失敗時は「もう一度」ですぐ同じステージを再開できます。別のタブに移った間は一時停止し、入力をリセットします。

## ファイル構成

```text
index.html                画面と操作UI
css/style.css             縦持ち・小画面・横持ち対応
js/engine.js              マップ、衝突、視線判定、経路探索、状態管理
js/game.js                Canvas描画、入力、演出、音
assets/images/            任意の差し替えPNGと説明
assets/audio/             任意の効果音MP3と説明
tests/engine.test.cjs      主要ルールの自動検証
tests/routes.cjs          店員が動く状態で3ステージのクリア経路検証
tests/ui.test.cjs          入力・描画アダプターの単体検証
```

画像は player.png / staff.png / staff_aggressive.png / clothes_target.png / clothes_messy.png を配置すると自動で読み込みます。未配置なら図形で描画します。音声ファイルの命名は assets/audio/README.md を参照してください。未配置時は電子音で代替します。音は起動時OFFです。

## 状態と保守

ゲーム状態は title / playing / chasing / caught / gameover / timeout / clear / final。捕獲演出中は操作とタイマーを止め、約1.1秒後に結果を表示します。結果処理はプレイ中にしか実行されないため二重終了しません。

店員は patrol（巡回）→ alert（発見）→ chase（追跡）→ lost（見失い）→ return（巡回地点に復帰）の状態を持ちます。アイテムに気づいたときは distract（棚へ移動）→ fold（整理）→ return。追跡は最後に見えた位置へ向かい、遮蔽物越しの現在位置を参照しません。マップと難易度は engine.js 冒頭で編集できます。

## 確認結果

Node.jsがある場合、このフォルダーから実行できます。

```sh
node tests/engine.test.cjs
node tests/routes.cjs
node tests/ui.test.cjs
```

主要ルール9項目に加え、店員AIを有効にした移動シミュレーションで全ステージ45秒以内のクリアを確認しました。UIの単体検証では画像・音声がない状態、キーボード・スティック・入力解除を確認しています。

**検証の制約：** ブラウザー操作ツールのURLポリシーがローカルファイル表示を拒否したため、実ブラウザーでのプレイ、実画面でのレイアウト、実スマートフォンのタッチ操作は未確認です。単体テストはその代替を保証するものではありません。
